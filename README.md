# ITB Wildlife (work in progress)

Standalone animal-behaviour plugin for Skyrim Special Edition, part of the Instincts The Beastmaster project. No dependencies beyond the base game and its official DLC.

## Status
Phase 1 done: 694 records (538 AI packages, 76 factions, 65 form lists, 8 keywords, 7 combat styles) with new names and new FormIDs. Masters: Skyrim.esm, Update.esm, Dawnguard.esm, Dragonborn.esm.

Planned: species tweaks (speed, acceleration, confidence) with the project's stagger caps, package assignment to creatures, and Beast Harmony DLL rules that keep them applied.

## Layout
- `Plugin/ITB Wildlife.esp`: built plugin.
- `Source/yaml/`: the plugin as Spriggit YAML (Spriggit 0.41, Skyrim SE).
